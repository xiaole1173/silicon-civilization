# 错层 · SEAM

一个盒子里的走廊。两条轨道在共用的棱上对到同一高度时，拐角就通了。

这是 Week 05 3D 游戏的**可玩原型**：只验证一个核心手感——“把两个面上的东西接上”那一下是否成立。
正式关卡会在这个骨架上扩到 3 个接缝谜题 + 一段灵异短故事。

## 怎么跑

需要 Python（本机已装 3.14）或任何静态文件服务器。**不能直接双击 index.html**——
页面用了 ES module，`file://` 协议会被浏览器的同源策略拦掉，白屏。

```
cd w05_3d_game
python -m http.server 8080
```

然后浏览器打开 http://localhost:8080

Windows 上也可以直接双击 `run.bat`，它会起服务并打开浏览器。

## 操作

| 动作 | 操作 |
|---|---|
| 转动视角 | 在**空白处**按住拖动（左右/上下） |
| 升降轨道 | 按住**轨道本体**上下拖动 |
| 静音 | M 键，或右下角「声音 开 / 关」 |
| 音量 | 右下角滑杆 |
| 重新开始 | R 键 |

目标：两条轨道的高度差小于 0.085 时，它们会在拐角处接上。

## Demo 模式

标题页点「观看演示」，会自动把 B 轨道推到与 A 对齐，全程不需要操作。
这就是作业要求的 Demo 按钮的原型：它在跑真实游戏，不是播视频；按 R 可以随时重来。

也可以在 URL 后面加参数直接进入某个状态（用于截图和自查）：

- `?auto=1` 跳过标题页
- `?auto=demo` 直接演示
- `?auto=revealed` 直接到揭示状态

## 声音

全部是 WebAudio 实时合成的，**没有任何音频文件**，因此零版权风险：

- 环境嗡鸣：三个失谐低频正弦 + 0.06Hz 的音量起伏
- 转动/抓取：短噪声 + 带通滤波
- 对齐提示：音高随高度差收窄而升高（越接近越"准"）
- 接通：噪声爆点 + 三角波
- 灯亮：两个五度关系的正弦

浏览器要求用户手势后才能出声，所以点「开始」之前是静音的，这是正常的。

## 测试环境

- Microsoft Edge 155.0.4283.62（Chromium 内核），Windows 11
- 未在 Firefox / Safari 上测试

## 已知限制

- 视角只能小幅环绕（左右各 20 度），还不能转 90 度看别的面——因为其余四个面还没有内容
- 只有 1 个接缝谜题，一局约 40 秒
- 无移动端适配
- 人物是几何体拼的剪影，不是模型

## 技术要点

- Three.js 0.169.0，**本地 vendor**，不依赖 CDN，断网可跑
- 零构建：原生 ES module + importmap
- 判定是**一维标量比较**（两条轨道的高度差），不做任何屏幕空间的图形匹配
- 对齐后由状态机驱动光球沿折线走一遍，而不是物理
